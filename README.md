# Тест «Какой вид спорта тебе подходит?»

Небольшой адаптивный веб-тест, который сопоставляет ответы пользователя с девятью видами спорта. Проект работает как статический сайт: для запуска не нужны сервер, сборка или установка зависимостей.

## Возможности

- 14 вопросов с четырьмя вариантами ответа.
- Семь параметров, по которым анализируются предпочтения.
- Девять возможных спортивных результатов.
- Расчёт процента соответствия для каждого вида спорта.
- Распределение параметров в процентах относительно максимального значения в текущем результате.
- Основной результат с описанием и профилем предпочтений.
- Отображение всех совместных лидеров при точном равенстве максимальных результатов.
- Индикатор прохождения, возврат к предыдущему вопросу и повторное прохождение.
- Возможность поделиться результатом через системное меню устройства или скопировать текст результата.
- Переключение между светлой и тёмной темами с сохранением выбора.
- Адаптация интерфейса для мобильных устройств и компьютеров.

## Виды спорта

1. Вейкборд
2. Серфинг
3. Скалодром
4. Сапбординг (SUP)
5. Каякинг
6. Теннис
7. Коньки
8. Ролики
9. Скейтбординг

## Как устроен подсчёт

Каждый вариант ответа начисляет:

- **2 балла** — основному параметру;
- **1 балл** — вторичному параметру.

После ответа на все вопросы баллы параметров умножаются на веса соответствующего вида спорта и суммируются.

Формула процента соответствия:

```text
100 × Σ(балл параметра × вес параметра) / (28 × сумма весов вида спорта)
```

Результаты сортируются по проценту соответствия в порядке убывания.

- Если несколько видов спорта набрали одинаковый максимальный результат, они отображаются как совместные лидеры. Случайный выбор победителя не используется.

Проценты отражают соответствие ответов весовой модели теста. Это не вероятность спортивного успеха, не медицинская рекомендация и не объективная оценка физических способностей.

## Запуск локально

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в современном браузере.

Для локального просмотра не требуется устанавливать пакеты или запускать сервер.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Добавьте `index.html` и этот `README.md` в корень репозитория.
3. Откройте в репозитории **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`;
   - **Branch:** `main` (или другую ветку, в которую загружен сайт);
   - **Folder:** `/ (root)`.
5. Нажмите **Save**.
6. Дождитесь завершения публикации. Адрес сайта появится в разделе **Settings → Pages**.

Если репозиторий называется `username.github.io`, сайт будет опубликован в корне домена: `https://username.github.io/`. Для обычного репозитория используется адрес вида `https://username.github.io/repository-name/`.

## Настройка теста

Вопросы, варианты ответов, параметры, веса и тексты результатов находятся в данных внутри `index.html`. При изменении вопросов или начислений проверьте, что:

- у каждого вопроса остаются корректные варианты ответов;
- ключи параметров совпадают с ключами в матрице весов;
- веса всех видов спорта заданы для используемых параметров;
- формула и правило обработки близких результатов соответствуют актуальной спецификации.
